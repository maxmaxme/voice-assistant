Call this in the same response as an action tool when the action needs no spoken reply (switching devices, opening or closing something, a scene or a script). The user hears a short sound instead of speech: `on` = something was switched on, opened or started; `off` = switched off, closed or stopped; `done` = anything else. Say nothing yourself. If the action fails you get the result back and must say so briefly. Never use it when the user asked a question or expects an answer.
