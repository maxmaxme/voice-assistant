Sets the target temperature of a climate entity.

When the user names a target temperature while the unit is off or in a non-thermal mode, set an appropriate mode too — **cool** when the room is warmer than the target, **heat** when it is cooler (check with `GetLiveContext` if you don't already know the room temperature from this turn). Never claim success for the temperature while leaving the unit off. If a script in your tool list says it controls this kind of device, follow its description instead.
